# 📖 Chapter Notes Phone Application

## Overview

The Chapter Notes is a Java and XML-based mobile application designed for readers who want to organize and track their reading activities. The application allows users to manage their to-be-read list, add books they have completed, and rate the books they have read.

This project was developed as part of an academic requirement and serves as a portfolio project to demonstrate mobile application development skills, user interface design, and application functionality using Android development technologies.

## Objectives

* To develop a user-friendly mobile application for book readers
* To help users organize and monitor their reading progress
* To implement book tracking and rating functionalities
* To showcase practical Android development skills using Java and XML
  
## Technologies Used

* **Java** – Application logic and functionality
* **XML** – User interface design and layouts
* **Android Studio** – Mobile application development environment

## Project Scope & Limitations

* This application is designed for **mobile devices only**
* User data is stored locally within the application
* Online synchronization and cloud backup features are not currently implemented
* The application focuses mainly on book tracking and rating functionalities
